    Host on a Mac or Linux

    Hosting on a Mac or a Linux computer now uses Leyline's one-click hosting.

    What it is #

    Hosting on a Mac or Linux computer works the same way as on Windows: open play.openvanilla.app/wrath/host, press Start, and run the Mac / Linux starter file the page gives you. Or use the Host page of the Leyline launcher.

    Everything else, from invite links to the realm list, is in Host your own realm.

    Note: The older command-line host for Mac and Linux that this chapter used to describe is retired.
